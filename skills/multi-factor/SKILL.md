# A股多因子选股框架 (Multi-Factor Stock Selection)

本 Skill 提供一套完整的 **A股多因子量化选股系统**，基于免费公开接口（东方财富数据中心估值/F10财务/分红、腾讯/新浪K线）获取数据，无需任何 API Key，实现26个经典量化因子的计算、标准化与加权合成。

## 核心功能

- ✅ **26个经典量化因子**：覆盖价值、成长、质量、动量、波动、流动性六大维度
- ✅ **因子标准化**：Z-Score / Min-Max / Rank 三种方法，支持缩尾去极值
- ✅ **多因子合成**：等权 / IC加权 / 自定义权重 三种策略
- ✅ **智能筛选**：ST排除、市值过滤、行业限制
- ✅ **结果输出**：CSV + JSON 双格式，含排名、综合得分、各因子分项得分

## 因子体系详解

### 一、价值因子 (Value Factors)

| # | 因子名称 | 经济含义 | 计算方式 | 信号方向 |
|---|---------|---------|---------|---------|
| 1 | **PE_TTM** | 市盈率（滚动），衡量股价相对于每股收益的贵贱程度。越低表示估值越便宜 | 总市值 / 最近4季度净利润之和 | ⬇️ 越低越好 |
| 2 | **PB** | 市净率，衡量股价相对于每股净资产的溢价程度。反映资产重估空间 | 总市值 / 股东权益合计 | ⬇️ 越低越好 |
| 3 | **PS_TTM** | 市销率（滚动），适用于亏损或低利润公司。衡量收入变现能力 | 总市值 / 最近4季度营业收入之和 | ⬇️ 越低越好 |
| 4 | **PCF** | 市现率，衡量股价相对于经营现金流的比率。现金流比利润更难造假 | 东财估值明细 PCF_OCF_TTM | ⬇️ 越低越好 |
| 5 | **股息率** | 近12个月分红占股价的比例。高分红代表公司现金流充裕、回报股东意愿强 | 近12个月每股税前派息 / 最新价 × 100% | ⬆️ 越高越好 |

### 二、成长因子 (Growth Factors)

| # | 因子名称 | 经济含义 | 计算方式 | 信号方向 |
|---|---------|---------|---------|---------|
| 6 | **营收同比增长率** | 营业收入的同比增速，反映公司业务扩张能力 | F10最新报告期营收同比（TOTALOPERATEREVETZ） | ⬆️ 越高越好 |
| 7 | **净利润同比增长率** | 净利润的同比增速，反映盈利增长质量 | F10最新报告期归母净利同比 | ⬆️ 越高越好 |
| 8 | **ROE同比变化** | ROE的年度变化量，衡量盈利能力改善趋势 | 本期加权ROE - 去年同期加权ROE | ⬆️ 越高越好 |
| 9 | **EPS增长率** | 每股收益的增长率，直接影响股价内在价值 | F10最新报告期基本EPS同比 | ⬆️ 越高越好 |
| 10 | **扣非净利润增速** | 扣除非经常性损益后的净利润增速，排除一次性收益干扰 | F10最新报告期扣非净利同比 | ⬆️ 越高越好 |

### 三、质量因子 (Quality Factors)

| # | 因子名称 | 经济含义 | 计算方式 | 信号方向 |
|---|---------|---------|---------|---------|
| 11 | **ROE** | 净资产收益率，巴菲特最看重的指标。衡量股东资金的回报效率 | F10加权净资产收益率（ROEJQ） | ⬆️ 越高越好 |
| 12 | **ROA** | 总资产收益率，衡量全部资产的利用效率 | F10总资产收益率（ZZCJLL） | ⬆️ 越高越好 |
| 13 | **毛利率** | 产品或服务的定价能力和成本控制能力 | F10销售毛利率 | ⬆️ 越高越好 |
| 14 | **净利率** | 最终盈利能力，扣除所有费用后的利润占比 | F10销售净利率 | ⬆️ 越高越好 |
| 15 | **资产负债率** | 财务杠杆水平。过高有破产风险，过低可能未充分利用杠杆 | F10资产负债率 | ⬇️ 越低越好 |
| 16 | **经营现金流/净利润比率** | 盈利质量指标。>1说明利润有现金支撑，<1可能存在应收账款堆积 | 每股经营现金流 / \|基本EPS\| × 100% | ⬆️ 越高越好 |

### 四、动量因子 (Momentum Factors)

| # | 因子名称 | 经济含义 | 计算方式 | 信号方向 |
|---|---------|---------|---------|---------|
| 17 | **20日动量** | 短期价格趋势，捕捉近一个月的动量效应 | (今日收盘价 / 20日前收盘价 - 1) × 100% | ⬆️ 越高越好 |
| 18 | **60日动量** | 中期价格趋势，捕捉约两个月的动量效应 | (今日收盘价 / 60日前收盘价 - 1) × 100% | ⬆️ 越高越好 |
| 19 | **相对强度RS** | 个股相对于沪深300指数的超额表现。>1表示跑赢大盘 | 个股N日涨幅 / 沪深300 N日涨幅 | ⬆️ 越高越好 |
| 20 | **突破信号** | 当前价格接近或突破N日高点的程度，捕捉趋势启动 | (当前价 / N日最高价 - 1) × 100% | ⬆️ 越高越好 |

### 五、波动因子 (Volatility Factors)

| # | 因子名称 | 经济含义 | 计算方式 | 信号方向 |
|---|---------|---------|---------|---------|
| 21 | **20日历史波动率** | 短期价格波动程度，低波策略的核心指标 | 日收益率标准差 × √252（年化）× 100% | ⬇️ 越低越好 |
| 22 | **Beta系数** | 个股相对于大盘的系统性风险。>1表示比大盘更波动 | Cov(R_stock, R_market) / Var(R_market) | ⬇️ 越低越好 |
| 23 | **最大回撤** | 近60日内从最高点到最低点的最大跌幅，衡量下行风险 | min((收盘价 - 累计最高价) / 累计最高价 × 100%) | ⬆️ 越接近0越好 |

### 六、流动性因子 (Liquidity Factors)

| # | 因子名称 | 经济含义 | 计算方式 | 信号方向 |
|---|---------|---------|---------|---------|
| 24 | **换手率** | 近N日平均换手率，反映交易活跃程度和资金关注度 | mean(每日成交量 / 流通股本)，流通股本=流通市值/收盘价 | ⬆️ 越高越好 |
| 25 | **成交额排名分位** | 个股成交额相对水平（简化版返回绝对值，单位亿元） | 近N日日均成交额（源不含成交额字段时按 成交量×典型价 推算） | ⬆️ 越高越好 |
| 26 | **Amihud非流动性指标** | Amihud(1995)提出的经典流动性度量。值越大表示越难交易 | mean(\|收益率\| / 成交额) × 10⁸ | ⬇️ 越低越好 |

## 多因子合成方法论

### 1. 因子预处理流程

```
原始数据 → 缺失值处理 → 缩尾去极值(Winsorize) → 标准化(Z-Score/Rank/Min-Max) → 方向统一
```

**缩尾去极值 (Winsorize)**：将超出1%和99%分位数的极端值截断到边界，防止异常值主导因子得分。

**标准化方法对比**：

| 方法 | 公式 | 适用场景 |
|------|------|---------|
| **Z-Score** | (x - μ) / σ | 因子近似正态分布时效果最佳 |
| **Rank** | rank(x) / N | 对异常值鲁棒，推荐默认使用 |
| **Min-Max** | (x - min) / (max - min) | 需要0-1归一化时使用 |

### 2. 信号方向统一

所有因子统一转换为 **"越高越好"** 的方向：
- 原始方向为"越低越好"的因子（如PE、PB、波动率），取负号反转
- 方向定义见 `FactorCombiner.SIGNAL_DIRECTIONS`

### 3. 加权合成策略

| 方法 | 说明 | 适用场景 |
|------|------|---------|
| **等权 (Equal Weight)** | 所有因子权重相等，简单稳健 | 默认推荐，因子间相关性低时效果佳 |
| **IC加权** | 根据因子与未来收益的IC（信息系数）分配权重 | 有历史回测数据时使用 |
| **自定义权重** | 用户手动指定各因子权重 | 基于主观判断或特定策略需求 |

## 使用方法

### 方式一：命令行调用

```bash
# 1. 单因子筛选（仅计算PE_TTM）
python multi_factor.py --stocks "贵州茅台,宁德时代,比亚迪" --factors PE_TTM

# 2. 多因子组合选股（等权合成，默认全部26个因子）
python multi_factor.py \
    --stocks "贵州茅台,宁德时代,比亚迪,东方财富,招商银行" \
    --weight equal_weight \
    --top_n 5

# 3. 自定义权重选股（价值+质量组合）
python multi_factor.py \
    --stocks "贵州茅台,宁德时代,比亚迪,东方财富,招商银行" \
    --factors PE_TTM,PB,ROE,毛利率 \
    --weight custom \
    --weights '{"PE_TTM":0.3,"PB":0.2,"ROE":0.3,"毛利率":0.2}'

# 4. 完整选股（全部因子 + ST排除 + 市值过滤）
python multi_factor.py \
    --stocks "贵州茅台,宁德时代,比亚迪,东方财富,招商银行,万科A" \
    --exclude_st \
    --min_cap 50 \
    --top_n 10

# 5. 使用Rank标准化（对异常值更鲁棒）
python multi_factor.py \
    --stocks "贵州茅台,宁德时代,比亚迪" \
    --standardize rank \
    --weight equal_weight
```

### 方式二：Python API调用

```python
from multi_factor import MultiFactorSelector

# 初始化选股器（免费公开接口，无需 API Key）
selector = MultiFactorSelector()

# 定义股票池
stocks = ["贵州茅台", "宁德时代", "比亚迪", "东方财富", "招商银行"]

# 运行选股
result = selector.run_selection(
    stock_names=stocks,
    factors=["PE_TTM", "PB", "ROE", "毛利率", "20日动量"],  # 指定因子
    filters={"exclude_st": True, "min_market_cap": 50},      # 筛选条件
    standardize_method="zscore",                              # 标准化方法
    weight_method="equal_weight",                             # 合成方法
    top_n=10,                                                 # Top N
    output_dir="./output"                                     # 输出目录
)

# 查看结果
print(result["results"])  # Top N 选股列表
```

### 方式三：单因子查询

```python
from multi_factor import MultiFactorSelector

selector = MultiFactorSelector()

# 查询单个股票的单个因子
pe = selector.compute_single_factor("贵州茅台", "PE_TTM")
print(f"贵州茅台 PE_TTM: {pe}")

# 查询单个股票的全部因子
factors = selector.compute_factors_for_stock("贵州茅台")
for name, value in factors.items():
    if value is not None:
        print(f"  {name}: {value:.4f}")
```

| 参数 | 类型 | 默认值 | 说明 |

## 注意事项

1. **接口限流**：免费公开接口对高频请求会限流，脚本已内置退避重试与多源切换，批量选股仍建议控制股票池规模
2. **数据质量**：部分财务指标可能因财报未披露而缺失，框架会自动跳过缺失值
3. **因子相关性**：使用前建议检查因子间的相关性矩阵，高度相关的因子可能导致重复加权
4. **回测验证**：生产环境使用前务必进行历史回测验证因子有效性
5. **ST股识别**：通过股票名称中的"ST"/"退"关键字判断，可能不够精确
