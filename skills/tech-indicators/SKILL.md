# A股技术分析指标库

基于腾讯/东方财富公开行情接口获取A股历史K线数据（免费、无需 API Key），自动计算 **10种经典技术指标**，输出买卖信号与综合研判结果。

## 功能概览

| # | 指标 | 说明 | 核心信号 |
|---|------|------|----------|
| 1 | MACD | 指数平滑异同移动平均线 | DIF/DEA金叉死叉、柱状图动能 |
| 2 | KDJ | 随机指标（K/D/J三线） | K/D金叉死叉、J值超买超卖 |
| 3 | RSI | 相对强弱指数（6/12/24周期） | 超买(>80)/超卖(<20) |
| 4 | BOLL | 布林带（上中下轨） | 突破上轨/跌破下轨、带宽变化 |
| 5 | MA均线 | 移动平均线（5/10/20/60/120/250日） | 多头排列/空头排列、MA5/MA10交叉 |
| 6 | SAR | 抛物线转向指标 | 趋势方向判断 |
| 7 | CCI | 顺势指标 | 强势(>+100)/弱势(<-100)区域 |
| 8 | WR | 威廉指标 | 超买(>-20)/超卖(<-80) |
| 9 | OBV | 能量潮 | 资金流入/流出判断 |
| 10 | VOL | 成交量均线（5/10/20日） | 放量/缩量判断 |

## ⚠️ 已知问题与修复

### calc_rsi() 参数兼容性（已修复）
```python
# ✅ 以下三种调用方式均正常：
from tech_indicators import calc_rsi
import pandas as pd
close = pd.Series([...])

rsi1 = calc_rsi(close)           # 默认 [6, 12, 24] → {'RSI6': ..., 'RSI12': ..., 'RSI24': ...}
rsi2 = calc_rsi(close, 14)       # 单个int → {'RSI14': ...}
rsi3 = calc_rsi(close, [9])      # list[int] → {'RSI9': ...}
```
**修复历史**: v2.0前 `calc_rsi()` 只接受 `List[int]`，传入单个 int 会报 `'int' object is not iterable`。现已改为 `Union[int, List[int]]` 自动转换。边界值（全涨→RSI=100，全跌→RSI=0）也已修正。

### calc_kdj() 需要三个Series参数
```python
kdj = calc_kdj(high, low, close)  # high/low/close都必须是pd.Series
```

## 指标详解与交易信号解读

### 1. MACD（指数平滑异同移动平均线）

**计算公式：**
- EMA_fast = EMA(Close, 12)
- EMA_slow = EMA(Close, 26)
- DIF = EMA_fast - EMA_slow
- DEA = EMA(DIF, 9)
- Histogram = (DIF - DEA) × 2

**参数说明：**
| 参数 | 默认值 | 含义 |
|------|--------|------|
| fast | 12 | 快速EMA周期 |
| slow | 26 | 慢速EMA周期 |
| signal | 9 | DEA信号线周期 |

**交易信号解读：**
- **金叉（DIF上穿DEA）**：买入信号，多头动能增强
- **死叉（DIF下穿DEA）**：卖出信号，空头动能增强
- **红柱放大**：上涨动能持续增强
- **绿柱放大**：下跌动能持续增强
- **零轴上方金叉**：强势区域买入信号更可靠
- **零轴下方死叉**：弱势区域卖出信号更可靠

### 2. KDJ（随机指标）

**计算公式：**
- RSV = (Close - Lowest_Low(n)) / (Highest_High(n) - Lowest_Low(n)) × 100
- K = (m1-1)/m1 × K_prev + 1/m1 × RSV
- D = (m2-1)/m2 × D_prev + 1/m2 × K
- J = 3K - 2D

**参数说明：**
| 参数 | 默认值 | 含义 |
|------|--------|------|
| n | 9 | RSV计算周期 |
| m1 | 3 | K线平滑系数 |
| m2 | 3 | D线平滑系数 |

**交易信号解读：**
- **K上穿D（金叉）**：买入信号，尤其在低位(20以下)更可靠
- **K下穿D（死叉）**：卖出信号，尤其在高位(80以上)更可靠
- **J > 100**：超买区域，考虑减仓
- **J < 0**：超卖区域，考虑建仓
- **顶背离**：股价创新高但KDJ未创新高 → 见顶信号
- **底背离**：股价创新低但KDJ未创新低 → 见底信号

### 3. RSI（相对强弱指数）

**计算公式：**
- Δ = Close - Close_prev
- Gain = Δ > 0 ? Δ : 0，Loss = Δ < 0 ? |Δ| : 0
- RS = MA(Gain, n) / MA(Loss, n)
- RSI = 100 - 100/(1 + RS)

**参数说明：**
| 周期 | 用途 |
|------|------|
| RSI6 | 短期强弱，灵敏度高 |
| RSI12 | 中期强弱，平衡灵敏度与稳定性 |
| RSI24 | 长期强弱，趋势判断 |

**交易信号解读：**
- **RSI > 80**：超买区域，股价可能回调
- **RSI < 20**：超卖区域，股价可能反弹
- **RSI从50上方回落至50下方**：转弱信号
- **RSI从50下方回升至50上方**：转强信号

### 4. BOLL（布林带）

**计算公式：**
- MID = MA(Close, 20)
- UPPER = MID + 2 × STD(Close, 20)
- LOWER = MID - 2 × STD(Close, 20)

**参数说明：**
| 参数 | 默认值 | 含义 |
|------|--------|------|
| period | 20 | 中轨均线周期 |
| num_std | 2.0 | 标准差倍数 |

**交易信号解读：**
- **股价突破上轨**：超买风险，可能回调
- **股价跌破下轨**：超卖机会，可能反弹
- **带宽收窄（缩口）**：变盘前兆，即将选择方向
- **带宽扩大（开口）**：趋势加速中
- **沿上轨运行**：强势上涨通道
- **沿下轨运行**：弱势下跌通道

### 5. MA均线系统

**计算公式：**
- MA(n) = SUM(Close, n) / n

**参数说明：**
| 周期 | 名称 | 用途 |
|------|------|------|
| MA5 | 周线 | 短期趋势，超短线操作参考 |
| MA10 | 半月线 | 短期支撑/压力 |
| MA20 | 月线 | 中期趋势，波段操作参考 |
| MA60 | 季线 | 中长期趋势分界 |
| MA120 | 半年线 | 牛熊分界线之一 |
| MA250 | 年线 | 长期牛熊分界线 |

**交易信号解读：**
- **多头排列（MA5 > MA10 > MA20）**：上升趋势，持股待涨
- **空头排列（MA5 < MA10 < MA20）**：下降趋势，空仓观望
- **MA5上穿MA10**：短线买入信号
- **MA5下穿MA10**：短线卖出信号
- **股价站稳MA60上方**：中期趋势向好

### 6. SAR（抛物线转向指标）

**计算公式：**
- SAR(n) = SAR(n-1) + AF × (EP - SAR(n-1))
- AF从初始值开始，每创新高/新低增加step，最大af_max

**参数说明：**
| 参数 | 默认值 | 含义 |
|------|--------|------|
| af_init | 0.02 | 加速因子初始值 |
| af_step | 0.02 | 每次递增步长 |
| af_max | 0.20 | 加速因子上限 |

**交易信号解读：**
- **股价在SAR上方**：上升趋势，持有或买入
- **股价在SAR下方**：下降趋势，卖出或观望
- **SAR由下翻上**：趋势反转向上，买入信号
- **SAR由上翻下**：趋势反转向下，卖出信号

### 7. CCI（顺势指标）

**计算公式：**
- TP = (High + Low + Close) / 3
- MA_TP = MA(TP, n)
- MD = MA(|TP - MA_TP|, n)
- CCI = (TP - MA_TP) / (0.015 × MD)

**参数说明：**
| 参数 | 默认值 | 含义 |
|------|--------|------|
| period | 14 | 计算周期 |

**交易信号解读：**
- **CCI > +100**：强势区域，可能超买
- **CCI < -100**：弱势区域，可能超卖
- **CCI从+100上方回落**：卖出信号
- **CCI从-100下方回升**：买入信号
- **-100 ~ +100之间**：常态波动区间

### 8. WR（威廉指标）

**计算公式：**
- WR = -100 × (Highest_High(n) - Close) / (Highest_High(n) - Lowest_Low(n))

**参数说明：**
| 参数 | 默认值 | 含义 |
|------|--------|------|
| period | 14 | 计算周期 |

**交易信号解读：**
- **WR > -20（接近0）**：超买区域，考虑卖出
- **WR < -80（接近-100）**：超卖区域，考虑买入
- **WR从-80下方回升至-80上方**：买入信号
- **WR从-20上方回落至-20下方**：卖出信号

> ⚠️ 注意：WR是反向指标，数值越大（越接近0）表示超买，数值越小（越接近-100）表示超卖。

### 9. OBV（能量潮）

**计算公式：**
- 若 Close > Close_prev → OBV = OBV_prev + Volume
- 若 Close < Close_prev → OBV = OBV_prev - Volume
- 若 Close = Close_prev → OBV = OBV_prev

**交易信号解读：**
- **OBV持续上升**：资金流入，支撑股价上涨
- **OBV持续下降**：资金流出，压制股价下跌
- **OBV与股价背离（价升量降）**：上涨动能不足，警惕回调
- **OBV与股价背离（价跌量增）**：可能有资金抄底

### 10. VOL成交量均线

**计算公式：**
- VOL_MA(n) = MA(Volume, n)

**参数说明：**
| 周期 | 用途 |
|------|------|
| MA5 | 短期量能趋势 |
| MA10 | 中期量能趋势 |
| MA20 | 长期量能趋势 |

**交易信号解读：**
- **放量（当日量 > MA5的150%）**：成交量显著放大，关注方向选择
- **缩量（当日量 < MA5的50%）**：成交量明显萎缩，市场观望情绪浓
- **价涨量增**：健康上涨趋势
- **价跌量增**：恐慌性抛售
- **价涨量缩**：上涨动能不足

## 综合研判逻辑

脚本对10个指标的信号进行汇总统计：

| 信号来源 | 买入条件 | 卖出条件 |
|----------|----------|----------|
| MACD | DIF/DEA金叉 | DIF/DEA死叉 |
| KDJ | K/D金叉 | K/D死叉 |
| RSI6 | < 20（超卖） | > 80（超买） |
| SAR | 上升趋势 | 下降趋势 |
| BOLL | 跌破下轨 | 突破上轨 |
| MA排列 | 多头排列 | 空头排列 |

**最终结论：**
- 买入信号 > 卖出信号 → 🟢 **偏多**
- 卖出信号 > 买入信号 → 🔴 **偏空**
- 无明确信号 → ⚪ **观望**

## 注意事项

1. **技术指标仅供参考**，不构成投资建议。实际交易应结合基本面、市场环境综合判断。
2. 不同时间周期的指标信号可能矛盾，建议多周期共振确认。
3. 超买/超卖状态在强趋势行情中可能持续较长时间，不宜单一指标反向操作。
4. 公开行情接口有调用频率限制，批量分析时注意请求间隔。
