# A股市场情绪量化指标

基于东方财富公开行情接口（涨停板行情中心 + 指数K线）的A股市场情绪自动化分析工具，计算17项核心市场情绪指标并生成综合评分。

## 功能概述

- **涨跌统计类**：涨停/跌停家数、涨跌比、上涨/下跌分布、涨速指标
- **连板高度类**：最高连板天数、梯队分布、溢价率、炸板率
- **量能指标类**：换手率分位数、成交额变化率、量比统计、北向资金
- **恐慌贪婪指标**：A股恐惧贪婪指数、VIX类比波动率指标
- **综合情绪指数**：加权合成评分（0-100）、状态分类、趋势判断

## 依赖安装

```bash
pip install pandas numpy requests openpyxl
```

> 数据来自东方财富公开行情接口，免费且无需任何 API Key。
> 注：涨跌家数仅提供最新交易日快照、涨停板池子仅保留约两周、北向资金净买入额已停止披露，
> 相应指标在缺数据的日期会自动跳过（综合评分按剩余权重归一化）。

## 使用方法

### 基本用法

```bash
# 今日情绪报告（默认）
python market_sentiment.py

# 指定日期回查
python market_sentiment.py --date 2026-06-23

# 近N日历史情绪数据
python market_sentiment.py --history 10

# 详细报告模式（显示计算过程）
python market_sentiment.py --report

# 附加趋势分析
python market_sentiment.py --trend

# 自定义权重配置
python market_sentiment.py --config my_weights.json

# 指定输出目录
python market_sentiment.py --output ./my_data/
```

### 盘中监控场景

每15分钟运行一次，跟踪情绪变化：

```bash
while true; do
    python market_sentiment.py --trend
    sleep 900
done
```

### 盘后复盘场景

每日收盘后生成完整报告并保存历史数据：

```bash
python market_sentiment.py --report --trend --verbose
```

## 指标详解

### 一、涨跌统计类（权重30%）

#### 1. 全市场涨停家数/跌停家数
- **经济含义**：反映当日市场极端做多/做空力量的对比。涨停家数多说明赚钱效应强，跌停家数多说明恐慌情绪蔓延。
- **信号解读**：涨停>100且跌停<20 → 强势行情；涨停<30且跌停>50 → 弱势行情

#### 2. 涨跌停比（LTD Ratio）
- **经济含义**：涨停家数÷跌停家数，衡量市场多空力量对比的核心指标。
- **信号解读**：比值>5为极强，1-3为中性偏弱，<0.5为极弱

#### 3. 上涨/下跌/平盘家数
- **经济含义**：全市场个股涨跌分布，反映整体赚钱效应和市场广度。
- **信号解读**：上涨占比>60%为强势，<40%为弱势

#### 4. 涨速指标（上涨占比）
- **经济含义**：上涨家数占全市场的百分比，替代盘中5分钟涨幅>3%的活跃股统计。
- **信号解读**：>70%为加速上涨阶段，<30%为加速下跌阶段

### 二、连板高度类（权重25%）

#### 5. 最高连板天数（市场最高板）
- **经济含义**：市场最强个股的连续涨停天数，反映短线投机情绪的高度和持续性。
- **信号解读**：≥7天为极端亢奋，3-5天为正常活跃，≤2天为情绪冰点

#### 6. 连板梯队分布（2板/3板/4板+家数）
- **经济含义**：不同连板高度的个股数量分布，反映市场投机梯队的完整性。
- **信号解读**：梯队完整（各层级都有）→ 行情可持续；断层明显 → 情绪可能转折

#### 7. 昨日涨停今日表现（溢价率）
- **经济含义**：昨日涨停股今日的延续性，正值为溢价（接力意愿强），负值为折价（接力意愿弱）。
- **信号解读**：>5%为强势接力，<-5%为情绪退潮

#### 8. 炸板率（当日开板次数/涨停总次数）
- **经济含义**：涨停后未能封住的个股比例，反映涨停质量的可靠性。
- **信号解读**：<30%为高质量涨停，>60%为虚假繁荣

### 三、量能指标类（权重25%）

#### 9. 全市场换手率分位数（vs近N日）
- **经济含义**：当日换手率在历史同期中的相对位置，衡量交易活跃度。
- **信号解读**：>80%为高换手（可能见顶），<20%为低换手（可能见底）

#### 10. 成交额较前5日均值变化率
- **经济含义**：当日成交额与近期均值的偏离程度，反映资金进出方向。
- **信号解读**：>10%放量上涨为健康，缩量下跌为弱势

#### 11. 量比分布统计
- **经济含义**：当前成交量与均量的比值及其波动特征。
- **信号解读**：量比>1.5为明显放量，<0.7为明显缩量

#### 12. 北向资金净流入/流出
- **经济含义**：沪深港通资金的当日净流向，代表"聪明钱"的方向判断。
- **信号解读**：持续净流入>10亿为看多信号，持续净流出>50亿为看空信号

### 四、恐慌贪婪指标（权重20%）

#### 16. A股版恐惧贪婪指数（0-100）
- **经济含义**：综合涨停比、上涨占比、换手率分位数等多维度数据，量化市场整体情绪。
- **信号解读**：<20极度恐惧（可能见底），>80极度贪婪（可能见顶），40-60中性区间

#### 17. VIX类比指标（基于波动率）
- **经济含义**：以上证指数日收益率标准差计算的隐含波动率，类比美股VIX恐慌指数。
- **信号解读**：<20低波动(乐观)，>50高波动(恐慌)

## 情绪指数合成方法论

### 加权评分模型

综合情绪评分采用**多因子加权平均法**：

```
综合评分 = Σ(指标归一化值 × 权重) / Σ权重
```

各指标先归一化到0-100分，再按预设权重加权求和。默认权重配置见下方。

### 情绪状态分类

| 分数区间 | 状态   | emoji | 含义说明                    |
|---------|--------|-------|----------------------------|
| 0-25    | 冰点   | 🥶    | 市场极度悲观，可能接近底部     |
| 25-40   | 低迷   | 😔    | 情绪偏弱，观望为主           |
| 40-60   | 温和   | 😐    | 多空均衡，正常波动区间        |
| 60-80   | 亢奋   | 🔥    | 做多热情高涨，注意追高风险     |
| 80-100  | 过热   | 💥    | 情绪极端乐观，警惕回调风险     |

### 趋势判断逻辑

基于连续N日的综合评分变化方向：
- **上升**：连续N日评分递增 → 情绪回暖
- **下降**：连续N日评分递减 → 情绪退潮
- **震荡**：方向不一致 → 多空拉锯

## 自定义权重配置

创建 `sentiment_weights.json` 文件（或放在skill目录下作为默认配置）：

```json
{
    "limit_up_down_ratio": 8.0,
    "advance_decline_ratio": 7.0,
    "limit_up_count": 5.0,
    "speed_indicator": 3.0,
    "market_breadth": 7.0,
    "max_consecutive_limit": 8.0,
    "consecutive_distribution": 5.0,
    "yesterday_premium": 6.0,
    "break_board_rate": 6.0,
    "turnover_percentile": 7.0,
    "volume_change_rate": 6.0,
    "volume_ratio_stats": 6.0,
    "north_flow": 6.0,
    "fear_greed_index": 10.0,
    "vix_analog": 10.0
}
```

使用方式：`python market_sentiment.py --config sentiment_weights.json`

## 输出文件说明

- `sentiment_data/sentiment_history.json`：历史情绪数据时间序列（JSON数组）
- 每条记录包含：日期、各指标数值、综合评分、状态分类、趋势判断

## 注意事项

1. **数据源限制**：连板高度、炸板率等部分指标基于涨跌停数据的经验估算，非精确统计
2. **北向资金**：API返回格式可能变化，若无法获取则标记为"数据不可用"
3. **交易日识别**：周末/节假日无交易数据，回查时自动跳过
4. **盘中运行**：建议每15-30分钟刷新一次，避免频繁调用API
