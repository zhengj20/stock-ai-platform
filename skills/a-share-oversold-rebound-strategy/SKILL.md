# A股超跌反弹隔日短线选股策略 v2.3

## 简介

这是一套针对A股市场的隔日短线选股策略，核心逻辑是识别"超跌反弹"机会：当个股因大盘系统性下跌或板块普跌而非自身利空原因，单日跌幅达到6%-8%，且尾盘出现企稳信号时，次日存在较大概率高开，可在次日固定时间平仓获利。

## 一、核心选股逻辑

押注"错杀后修复性反弹"，核心是甄别下跌原因，而非单纯看跌幅数字。策略分两段：当日14:30推送选股池，次日9:45提醒平仓。

## 二、选股规则

### （一）跌幅与原因甄别
1. 当日跌幅6%-8%
2. 跌幅原因为大盘系统性下跌或板块普跌带动，非个股独立暴跌
3. 排除当日有重大负面公告、业绩预警、监管处罚、舆情危机的个股
4. 优先选近期非持续下跌趋势的个股（此前横盘或上涨，当日突发下跌，而非已连跌多日）

### （二）企稳信号
5. 尾盘（14:30后）跌幅较日内低点收窄，出现缩量企稳或资金回流迹象
6. 跌幅触及关键支撑位（前期密集成交区、MA60/MA120均线、前低点）
7. 大单/主力资金净流出当日呈收窄趋势，非持续放量出逃

### （三）风控排除项
8. 排除ST、*ST、有退市风险警示的股票
9. 排除当日跌停或跌幅超8%
10. 排除近3个月内有单日跌幅超15%"暴雷史"的个股
11. 排除沪深两市当日大幅下跌（跌超2%）且尾盘未现企稳信号的情况——大盘环境差时不推荐任何标的

### （四）板块与分散
12. 同一板块不超过2只，整体最多3只
13. 优先选流通市值适中个股（5亿-2000亿），规避过小盘股操纵风险及过大盘股反弹乏力问题

## 三、选股池输出格式

```
【YYYY年MM月DD日 隔日超跌反弹大概率高开股票池】

1. 代码：XXXXXX | 名称：XXX | 当前价格：XX.XX元 | 跌幅：-X.X% | 简要逻辑：XXX
2. 代码：XXXXXX | 名称：XXX | 当前价格：XX.XX元 | 跌幅：-X.X% | 简要逻辑：XXX
3. 代码：XXXXXX | 名称：XXX | 当前价格：XX.XX元 | 跌幅：-X.X% | 简要逻辑：XXX

（最多输出3只股票，若当日大盘环境不符合条件11，可输出"今日不推荐"）
```

## 四、次日9:45平仓提醒规则

1. 提醒时间：次日交易日上午 9:45 统一提醒平仓，不论开盘高开、平开或低开
2. 提醒内容：
   - 个股代码、名称
   - 9:45时点当前价格
   - 持仓盈亏（以选股池推送时的价格为买入成本价，计算盈亏金额及百分比）
   - 平仓操作建议
3. 输出格式：

```
【YYYY年MM月DD日 09:45 平仓提示】

1. 代码：XXXXXX | 名称：XXX | 买入价：XX.XX元 | 当前价：XX.XX元 | 盈亏：+X.X%（+XX.XX元/股）| 建议：平仓
2. 代码：XXXXXX | 名称：XXX | 买入价：XX.XX元 | 当前价：XX.XX元 | 盈亏：+X.X%（+XX.XX元/股）| 建议：平仓
```

## 五、推送要求

1. 选股池推送时间：每个交易日下午14:30定时发送
2. 平仓提醒时间：次日交易日上午9:45定时发送
3. 推送限制：周末、法定节假日不推送
4. 必备要素：
   - 选股池：完整日期、个股当前价格、当日跌幅
   - 平仓提醒：完整日期、买入价、当前价、盈亏

## 六、数据源与自动化实现

### 6.1 数据源架构（v2.3 — 直连API，不依赖akshare）

| 数据类型 | 接口 | 来源 | 用途 |
|---------|------|------|------|
| A股全市场实时行情 | `vip.stock.finance.sina.com.cn` 分页API | 新浪财经 | 股价/涨跌幅/市值/换手率等基础筛选 |
| 指数实时行情 | `hq.sinajs.cn/list=sh000001,...` | 新浪财经 | 大盘环境判断（上证/深证/创业板） |
| 个股分时数据 | `push2his.eastmoney.com/trends2/get` | 东方财富 | 尾盘企稳信号检测 |
| 个股日K历史 | `push2his.eastmoney.com/kline/get` | 东方财富 | 暴雷史检查（近90天） |
| 板块/行业信息 | `push2.eastmoney.com/stock/get` (f57字段) | 东方财富 | 板块归属与分散控制 |

**备用方案**: 当东方财富接口不可用时，板块信息按代码前缀推断：68x→科创板, 30x→创业板, 6xx→沪市主板, 其他→深市主板。指数数据也有新浪和东方财富双源容错。

### 6.3 脚本核心流程

```
screen 命令:
  1. 获取全市场实时行情（新浪分页API，按涨跌幅升序，命中范围后提前终止）
  2. 检查大盘环境（三大指数涨跌，任一跌超-2%且无企稳→今日不推荐）
  3. 筛选跌幅6%-8%的个股
  4. ST/跌停过滤
  5. 流通市值过滤（5亿-2000亿）
  6. 深度筛选（最多检查30只）：
     a. 暴雷史检查（近90天日K，单日跌幅<-15%→排除）
     b. 尾盘企稳检测（分时数据，14:30后回升>0.3%→标记✓）
     c. 板块分散控制（同板块≤2只，总计≤3只）
  7. 输出选股池 + 保存 pool.json

closehold 命令:
  1. 加载 pool.json
  2. 获取实时行情更新当前价
  3. 计算盈亏并输出平仓提醒
```

### 6.4 API接口详情

#### A股全市场实时行情（新浪财经）

**URL**: `https://vip.stock.finance.sina.com.cn/quotes_service/api/json_v2.php/Market_Center.getHQNodeData`

| 参数 | 值 | 说明 |
|------|-----|------|
| page | 1,2,... | 页码（每页80条） |
| num | 80 | 每页数量 |
| sort | changepercent | 按涨跌幅排序 |
| asc | 1 | 升序（跌幅最大在前） |
| node | hs_a | 沪深A股 |

**返回字段**: code, name, trade(最新价), changepercent(涨跌幅%), pricechange(涨跌额), open, high, low, volume, amount, per(市盈率), pb(市净率), mktcap(总市值/万元), nmc(流通市值/万元), turnoverratio(换手率%)

> **注意**: 新浪返回的市值单位为**万元**，脚本内部已自动转换为元。

#### 指数行情（新浪财经）

**URL**: `https://hq.sinajs.cn/list=sh000001,sz399001,sz399006`
> **注意**: 必须用 `list=` 拼接在URL中，不能用params传参。

| 代码 | 名称 |
|------|------|
| sh000001 | 上证指数 |
| sz399001 | 深证成指 |
| sz399006 | 创业板指 |

**返回格式**: `var hq_str_sh000001="名称,开盘,昨收,当前,最高,最低,...";`
涨跌幅 = (当前 - 昨收) / 昨收 × 100%

#### 分时数据（东方财富）

**URL**: `https://push2his.eastmoney.com/api/qt/stock/trends2/get`

| 参数 | 值 | 说明 |
|------|-----|------|
| secid | 1.600519 / 0.000001 | 前缀: 沪市=1, 深市=0 |
| fields1 | f1,f2,...,f11 | 基础字段 |
| fields2 | f51,...,f58 | 扩展字段 |
| ndays | 1 | 仅当日 |

**返回格式**: `trends` 数组，每条为 `"日期时间,价格,开盘,最高,最低,成交量,成交额,振幅"`（逗号分隔）

#### 历史K线（东方财富）

**URL**: `https://push2his.eastmoney.com/api/qt/stock/kline/get`

| 参数 | 值 | 说明 |
|------|-----|------|
| klt | 101 | 日K线 |
| fqt | 1 | 前复权 |
| lmt | 90 | 最近N天数据 |

**返回格式**: `klines` 数组，每条为 `"日期,开盘,收盘,最高,最低,成交量,涨跌幅%"`

#### 板块信息（东方财富）

**URL**: `https://push2.eastmoney.com/api/qt/stock/get`
字段: f57(所属行业), f124(所属概念)

### 6.5 容错机制

- **API重试**: `api_call()` 包装器，3次指数退避（2s, 4s, 8s）
- **双源容错**: 指数数据优先新浪，失败后尝试东方财富备用接口
- **板块降级**: 东方财富不可用时按代码前缀推断板块归属
- **优雅降级**: 暴雷史/尾盘检查失败时不阻断流程（标记"待确认"而非排除）

## 八、已知问题与排障

### 东方财富接口偶发连接拒绝

`push2his.eastmoney.com` 和 `push2.eastmoney.com` 在某些网络环境下可能返回 `RemoteDisconnected('Remote end closed connection without response')`。这是服务端限流或防火墙行为，不是代码错误。

**应对策略**:
- 脚本内置3次指数退避重试（2s, 4s, 8s）
- 暴雷史/尾盘检查失败时不阻断流程（标记"待确认"而非排除）
- 板块信息有备用推断方案

### 非交易时段行为

- 新浪行情接口在非交易时段仍返回收盘数据，可用于回测验证
- 东方财富分时/K线接口在部分时段可能不稳定
- `is_trading_day()` 会在脚本入口拦截周末/节假日，提前退出

### 市值单位陷阱

新浪财经返回的 `mktcap`（总市值）和 `nmc`（流通市值）单位为**万元**而非"亿"。脚本内部已自动乘以 `1e4` 转换为元。
