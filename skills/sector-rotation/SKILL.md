# A股板块轮动追踪 (Sector Rotation Tracker)

基于免费公开接口（新浪板块行情 + 腾讯指数行情）的A股行业/概念板块行情分析与热点切换跟踪工具。提供四大核心功能模块，帮助投资者把握板块轮动节奏、识别市场主线方向。

## 安装依赖

```bash
pip install numpy requests
```

无需任何 API Key，全部使用免费公开数据源。

## 快速开始

```bash
# 查看行业板块行情总览
python sector_rotation.py overview

# 概念板块行情总览
python sector_rotation.py overview --type concept

# 板块强度排名与RPS分析
python sector_rotation.py strength

# 热点题材追踪
python sector_rotation.py hot

# 轮动信号检测（风格切换+周期定位）
python sector_rotation.py signals
```

## CLI参数完整说明表

| 命令 | 参数 | 类型 | 默认值 | 说明 |
|------|------|------|--------|------|
| `overview` | `--type` | industry/concept | industry | 板块类型：行业/概念 |
| `overview` | `--top` | int | 30 | 显示前N名排行 |
| `strength` | `--period` | 20/60 | 20 | RPS展示口径（当前为当日截面计算） |
| `hot` | `--top` | int | 10 | 显示前N个热门概念 |
| `signals` | (无) | - | - | 自动检测所有轮动信号 |

## 功能模块详解

### 1. 板块行情总览 (`overview`)

获取A股全部行业/概念板块的实时行情数据（新浪板块源，一次拉取全量），按涨跌幅排序展示。

**输出内容：**
- 涨幅TOP N排行（含涨跌幅、均价、家数、成交额、领涨股及其涨幅）
- 跌幅TOP10排行
- 统计摘要：平均涨跌幅、最大/最小涨跌、涨跌板块数量分布

```bash
# 行业板块总览（49个新浪行业）
python sector_rotation.py overview --type industry --top 30

# 概念板块总览（170+个概念）
python sector_rotation.py overview --type concept --top 20
```

---

### 2. 板块强度排名 (`strength`)

对全部行业+概念板块（约220个）计算动量评分和RPS相对强度指标。

**输出内容：**
- 板块动量强度TOP20排名（含RPS百分位、领涨股信息）
- 突破信号识别：涨幅>3%且RPS≥70的强势板块
- 评分构成透明化展示（JSON输出中含公式）

**动量评分公式：**
```
动量评分 = 日涨跌幅×3 + 领涨股涨幅×1
```

**RPS指标：** 板块在所有板块中的百分位排名（0-100），数值越高表示相对越强。

```bash
python sector_rotation.py strength
```

**信号标记：**
- 🔥 涨幅>3%（强势突破）
- ⭐ RPS≥90（极强相对强度）

---

### 3. 热点题材追踪 (`hot`)

扫描全部概念板块（170+个），识别当日最强主题和新兴热点。

**输出内容：**
- 当日最强概念TOP N及所属主题分类
- 高动量概念识别（涨幅>5%的新兴热点）
- 概念关联图谱：按AI科技/新能源绿色/消费医药/政策主题/金融地产/军工航天六大类分组

```bash
python sector_rotation.py hot --top 10
```

---

### 4. 轮动信号检测 (`signals`)

综合多维度分析，判断当前市场风格偏好和板块轮动阶段。

**输出内容：**

#### 信号1：防御型 vs 进攻型行业轮动
- **防御型行业**：金融行业、电力行业、供水供气、食品行业、酿酒行业、生物制药、煤炭行业
- **进攻型行业**：电子器件、电子信息、传媒娱乐、发电设备、机械行业、飞机制造、船舶制造
- 判断方向：`进攻→防御`(避险) or `防御→进攻`(风险偏好上升)

#### 信号2：大小盘风格切换
- 对比沪深300(大盘) vs 中证1000(小盘)当日表现（腾讯指数实时行情）
- 输出：大盘占优 / 小盘占优 + 差值

#### 信号3：成长型 vs 价值型风格切换
- **成长型**：电子器件、电子信息、发电设备、生物制药、医疗器械、飞机制造
- **价值型**：金融行业、煤炭行业、石油行业、钢铁行业、建筑建材、水泥行业、房地产
- 输出：成长占优 / 价值占优 + 差值

#### 信号4：板块轮动周期定位
基于风格板块涨跌分布，判断当前所处阶段：
| 周期阶段 | 特征 | 操作建议 |
|----------|------|----------|
| 🟢 萌芽期 | 温和上涨为主，分化明显 | 寻找新主线，左侧布局 |
| 🟡 发酵期 | 热点扩散，多数板块跟涨 | 跟随趋势，关注持续性 |
| 🔴 高潮期 | 大幅上涨板块>40%，均值>2% | 注意追高风险，逐步减仓 |
| ⚫ 衰退期 | 整体偏弱，下跌为主 | 防御为主，控制仓位 |

```bash
python sector_rotation.py signals
```

## 板块轮动方法论

### 周期理论框架

A股板块轮动遵循经典的四阶段循环：

```
萌芽期 → 发酵期 → 高潮期 → 衰退期 → (新一轮)萌芽期
```

**各阶段特征：**

| 阶段 | 市场表现 | 资金行为 | 操作策略 |
|------|----------|----------|----------|
| **萌芽期** | 少数板块逆势走强，大盘震荡 | 聪明钱悄悄建仓 | 左侧布局，小仓位试错 |
| **发酵期** | 主线明确，跟风板块增多 | 机构加仓，游资接力 | 顺势而为，加大仓位 |
| **高潮期** | 全面普涨，散户涌入 | 资金加速流入后开始分歧 | 逐步止盈，不追高 |
| **衰退期** | 高位板块补跌，市场缩量 | 主力出货，资金观望 | 控制仓位，等待新周期 |

### 实战应用要点

1. **风格切换先行指标**：大小盘和成长/价值的切换通常领先于行业轮动1-3个交易日
2. **RPS强度过滤**：优先选择RPS>80的强势板块，避免弱势股拖累
3. **概念持续性判断**：连续3日以上保持前20名的概念更具持续性
4. **防御/进攻切换**：经济数据向好时进攻型占优，不确定性增加时防御型占优

## 数据源说明

- **行业板块行情**：新浪 `money.finance.sina.com.cn/q/view/newSinaHy.php`（49个行业，GBK编码）
- **概念板块行情**：新浪 `money.finance.sina.com.cn/q/view/newFLJK.php?param=class`（170+个概念）
- **指数行情**：腾讯 `qt.gtimg.cn`（沪深300/中证1000/创业板指/上证指数）
- 板块字段：名称、家数、均价、涨跌幅、成交量、成交额、领涨股（代码/名称/涨幅）

## 注意事项

1. 免费接口仅提供板块**当日截面**数据（涨跌幅/成交额/领涨股）；板块资金流向、5日/10日涨跌幅、换手率、涨跌家数、历史行情无免费数据源，原 `flow`（资金流向）与 `history`（历史回查）模块及资金流评分因子已随之移除
2. 新浪行业分类与申万行业名称不同（如"生物制药"对应申万"医药生物"），风格分类常量使用新浪实际板块名
3. 盘中数据为实时快照，收盘后数据更完整准确
4. RPS和动量评分基于当日截面数据计算，非时间序列指标
