# A股K线形态识别系统

## Python API使用

### 重要：所有检测函数接收 **pandas DataFrame**，不是numpy数组

```python
import pandas as pd
from kline_patterns import (
    detect_bullish_engulfing,   # 看涨吞没
    detect_bearish_engulfing,   # 看跌吞没
    detect_morning_star,        # 早晨之星
    detect_evening_star,        # 黄昏之星
    detect_doji,                # 十字星
    detect_hammer,              # 锤子线
    detect_shooting_star,       # 流星线
)

# ✅ 正确：传入DataFrame（需包含 open/high/low/close/volume 列）
df = pd.DataFrame({
    'open': [...], 'high': [...], 'low': [...],
    'close': [...], 'volume': [...]
})
signals = detect_bullish_engulfing(df)

# ❌ 错误：传入5个独立数组（会报参数数量错误）
signals = detect_bullish_engulfing(open, high, low, close, volume)
```

### API签名参考
| 函数 | 签名 | 说明 |
|------|------|------|
| `detect_bullish_engulfing(df)` | `(df: DataFrame) -> List[PatternSignal]` | 看涨吞没形态 |
| `detect_bearish_engulfing(df)` | `(df: DataFrame) -> List[PatternSignal]` | 看跌吞没形态 |
| `detect_doji(df)` | `(df: DataFrame) -> List[PatternSignal]` | 十字星 |
| `detect_big_yang(df, threshold=0.03)` | `(df, float) -> List[...]` | 大阳线（默认涨幅>3%） |
| `detect_bull_flag(df, flagpole_len=5, flag_len=8)` | `(df, int, int) -> List[...]` | 看涨旗形 |

### PatternSignal结构
```python
@dataclass
class PatternSignal:
    pattern_name: str      # 形态名称，如 "bullish_engulfing"
    index: int             # 发生位置（DataFrame行索引）
    confidence: float      # 置信度 (0.0-1.0)
    direction: str         # 'bullish' / 'bearish' / 'neutral'
```

## 使用方法

### 基本用法

```bash
# 扫描平安银行最近200根日K线，检测所有形态
python kline_patterns.py 000001 200

# 指定输出报告文件
python kline_patterns.py 600519 300 --output report.html

# 仅检测看涨信号
python kline_patterns.py 000858 150 --direction bullish

# 仅检测看跌信号
python kline_patterns.py 000858 150 --direction bearish

# 生成统计报告（JSON格式）
python kline_patterns.py 600036 250 --report stats.json
```

### 命令行参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `stock_code` | A股股票代码（6位数字） | 必填 |
| `periods` | 扫描最近N根K线 | 200 |
| `--output` | HTML报告输出路径 | 不生成 |
| `--report` | JSON统计报告输出路径 | 不生成 |
| `--direction` | 信号方向过滤：`bullish`/`bearish`/`all` | all |
| `--min-confidence` | 最低置信度阈值（0-1） | 0.5 |

## K线形态说明

### 一、单根K线形态

#### 1. 大阳线 / 大阴线（Big Yang/Yin Line）

**示意图：**
```
大阳线：        大阴线：
   ┃              ┏━━━┓
 ┏━━━┓            ┃   ┃
 ┃   ┃            ┃   ┃
 ┃   ┃            ┗━━━┛
 ┗━━━┛            ┃   ┃
                  ┃   ┃
```

**识别条件：** 实体长度 > 3%（收盘价相对开盘价的涨跌幅绝对值超过3%）

**交易含义：**
- **大阳线（看涨）**：多方强势进攻，通常出现在底部反转或突破位置时信号更强
- **大阴线（看跌）**：空方猛烈打压，高位出现时需警惕趋势反转

---

#### 2. 十字星（Doji）

**示意图：**
```
    ┃
━━━┫━━━   ← 开盘价 ≈ 收盘价
    ┃
```

**识别条件：** |收盘-开盘| < (最高-最低) × 10%，且上下影线明显

**交易含义：** 多空力量均衡，市场犹豫不决。出现在趋势末端时预示可能反转：
- **看涨**：下跌趋势中出现十字星 → 可能见底
- **看跌**：上涨趋势中出现十字星 → 可能见顶

---

#### 3. 锤子线 / 倒锤子线（Hammer / Inverted Hammer）

**示意图：**
```
锤子线：       倒锤子线：
 ┏━━━┓            ┃   ┃
 ┃   ┃            ┗━━━┛
    ┃              ┃   ┃
    ┃              ┃   ┃
    ┃              ┃   ┃
```

**识别条件：**
- **锤子线**：上影线 < 实体，下影线 > 2×实体，小实体在顶部
- **倒锤子线**：下影线 < 实体，上影线 > 2×实体，小实体在底部

**交易含义：**
- **锤子线（看涨）**：出现在下跌趋势末端，表示下方支撑强劲
- **倒锤子线（中性偏多）**：出现在下跌中可能预示反转，需后续确认

---

#### 4. 上吊线 / 射击之星（Hanging Man / Shooting Star）

**示意图：**
```
上吊线：       射击之星：
 ┏━━━┓            ┃   ┃
 ┃   ┃            ┗━━━┛
    ┃              ┃   ┃
    ┃              ┃   ┃
    ┃              ┃   ┃
```

**识别条件：** 形态与锤子/倒锤相似，但出现在不同趋势位置：
- **上吊线** = 锤子线形态 + 出现在上涨趋势中 → **看跌**
- **射击之星** = 倒锤子形态 + 出现在上涨趋势中 → **看跌**

**交易含义：** 两者均为顶部反转信号，表示多头力量衰竭。

---

#### 5. 纺锤线（Spinning Top）

**示意图：**
```
    ┃
━━━┫━━━   ← 小实体居中
    ┃
```

**识别条件：** 实体 < (最高-最低) × 30%，上下影线均较长

**交易含义：** 市场犹豫不决，多空拉锯。出现在趋势中预示动能减弱：
- **看涨/看跌**：取决于所处位置，通常需等待后续K线确认方向

---

#### 6. 蜻蜓十字 / T字线（Dragonfly Doji）

**示意图：**
```
━━━┳━━━   ← 开盘=收盘在顶部
    ┃
    ┃
    ┃
```

**识别条件：** 开盘≈收盘≈最高价，下影线明显 > 实体×3

**交易含义：** **看涨信号**。类似锤子线但更极端，表示盘中大幅下跌后被完全拉回，多头力量极强。

---

#### 7. 光头光脚阳线 / 阴线（Marubozu）

**示意图：**
```
光头光脚阳线：    光头光脚阴线：
 ┏━━━┓              ┏━━━┓
 ┃   ┃              ┃   ┃
 ┃   ┃              ┃   ┃
 ┗━━━┛              ┗━━━┛
```

**识别条件：** 无上下影线（或极短），开盘=最低且收盘=最高（阳）/ 开盘=最高且收盘=最低（阴）

**交易含义：**
- **光头光脚阳线（看涨）**：全天多方主导，强势信号
- **光头光脚阴线（看跌）**：全天空方主导，弱势信号

---

### 二、双根/三根K线形态

#### 8. 早晨之星 / 黄昏之星（Morning/Evening Star）

**示意图：**
```
早晨之星（看涨反转）：
 ┏━━━┓    ┃    ┏━━━┓
 ┃   ┃   ┃ ┃   ┃   ┃
 ┗━━━┛  ┏━━━┛ ┃   ┃
        ┃     ┗━━━┛

黄昏之星（看跌反转）：
 ┗━━━┛  ┗━━━┓  ┗━━━┛
 ┃   ┃      ┃  ┃   ┃
 ┏━━━┛    ┏━━━┛ ┃   ┃
```

**识别条件：**
- **早晨之星（看涨）**：第一根大阴线 + 第二根小实体（星线）向下跳空 + 第三根大阳线深入第一根实体
- **黄昏之星（看跌）**：第一根大阳线 + 第二根小实体向上跳空 + 第三根大阴线深入第一根实体

**交易含义：** 经典的三K反转形态，可靠性较高。

---

#### 9. 吞没形态（Bullish/Bearish Engulfing）

**示意图：**
```
阳包阴（看涨吞没）：    阴包阳（看跌吞没）：
 ┏━━━┓                 ┏━━━┓
 ┃   ┃                ┃   ┃
 ┗━━━┛               ┃   ┃
 ┏━━━━━━━━━━━━┓      ┗━━━┛
 ┃            ┃
 ┗━━━━━━━━━━━━┛
```

**识别条件：** 第二根K线实体完全包裹第一根K线实体，且颜色相反：
- **阳包阴（看涨）**：阴线后出现更大的阳线
- **阴包阳（看跌）**：阳线后出现更大的阴线

**交易含义：** 强烈的反转信号，表示市场力量发生根本性转变。

---

#### 10. 乌云盖顶 / Piercing Line

**示意图：**
```
乌云盖顶（看跌）：      Piercing（看涨）：
 ┏━━━┓                  ┏━━━┓
 ┃   ┃                 ┃   ┃
 ┗━━━┛                ┃   ┃
 ┏━━━━━━━━┓           ┗━━━┛
 ┃        ┃      ┏━━━━━━━━━━━━┓
 ┗━━━━━━━━┛      ┃            ┃
                  ┗━━━━━━━━━━━━┛
```

**识别条件：**
- **乌云盖顶（看跌）**：阳线后阴线开盘跳空高开，收盘深入第一根实体50%以上
- **Piercing Line（看涨）**：阴线后阳线开盘跳空低开，收盘深入第一根实体50%以上

**交易含义：** 趋势可能反转的预警信号。

---

#### 11. 平头顶部 / 底部（Flat Top/Bottom）

**示意图：**
```
平头顶部：              平头底部：
    ┃   ┃                ┃   ┃
    ┃   ┃                ┃   ┃
━━━┫   ┫━━━ ← 最高价齐平  ┗━━━┛
    ┃   ┃           ┏━━━┳━━━┓ ← 最低价齐平
```

**识别条件：** 相邻两根K线的最高价（顶部）或最低价（底部）基本一致（误差<1%）

**交易含义：**
- **平头顶部（看跌）**：两次冲高到同一价位受阻，阻力位明确
- **平头底部（看涨）**：两次探底到同一价位获支撑，支撑位明确

---

#### 12. 上升三法 / 下降三法（Three Methods）

**示意图：**
```
上升三法（看涨持续）：
 ┏━━━┓
 ┃   ┃    ┃ ┃ ┃ ┃
 ┗━━━┛  ┏━━━┫ ┫ ┫
        ┃   ┃ ┃ ┃
        ┗━━━┻━┻━┛

下降三法（看跌持续）：
 ┗━━━┛
 ┃   ┃    ┃ ┃ ┃ ┃
 ┏━━━┓  ┗━━━┳┳┳┓
 ┃   ┃      ┃ ┃ ┃
 ┏━━━┛  ┏━━━┻━┻━┛
```

**识别条件：**
- **上升三法（看涨）**：一根大阳线 + 3根小阴线回调（不突破第一根低点）+ 第五根大阳线创新高
- **下降三法（看跌）**：一根大阴线 + 3根小阳线反弹（不突破第一根高点）+ 第五根大阴线创新低

**交易含义：** 趋势中继形态，表示短暂整理后原趋势延续。

### 三、多根K线形态

#### 13. 头肩顶 / 头肩底（Head & Shoulders）

**示意图：**
```
头肩顶（看跌反转）：         头肩底（看涨反转）：
      ┃                        ┃
   ┃  ┃  ┃                  ┏━━━┛
   ┃  ┃  ┃               ┏━┛   ┗━┓
   ┃  ┃  ┃            ┏━━┛       ┗━━┓
───┻──┼──┻── ← 颈线    ┃             ┃
      ┃                ┗━━━━━━━━━━━━━┛
```

**识别条件：** 左肩-头部-右肩三个波峰/波谷，头部最高/最低，左右肩高度相近，突破颈线确认。

**交易含义：** 经典反转形态，可靠性高。头肩顶看跌，头肩底看涨。

---

#### 14. 双顶M头 / 双底W底（Double Top/W Bottom）

**示意图：**
```
双顶M头（看跌）：           双底W底（看涨）：
   ┃    ┃                    ┃    ┃
   ┃    ┃                   ┗┓    ┏┛
───┻────┻── ← 颈线          ┃    ┃
                            ┗━━━━━┛ ← 颈线
```

**识别条件：** 两个相近的高点（双顶）或低点（双底），中间有回调/反弹，突破颈线确认。

**交易含义：** 经典反转形态，M头看跌，W底看涨。

---

#### 15. 三角形整理（Symmetrical/Rising/Falling Triangle）

**示意图：**
```
对称三角形：       上升三角形：      下降三角形：
   ╲    ╱            ┃╲              ╱┃
    ╲  ╱             ┃ ╲            ╱ ┃
     ╲╱              ┃  ╲          ╱  ┃
                    ┃   ╲        ╱   ┃
```

**识别条件：** 连接高点和低点形成收敛趋势线：
- **对称三角形**：高点下降、低点上升，两线收敛
- **上升三角形**：高点水平、低点上升 → **看涨突破**
- **下降三角形**：高点下降、低点水平 → **看跌突破**

**交易含义：** 整理形态，突破方向决定后续走势。

---

#### 16. 旗形整理（Bull/Bear Flag）

**示意图：**
```
上升旗形（看涨持续）：    下降旗形（看跌持续）：
         ╱╲                 ╱
       ╱   ╲              ╱
     ╱      ╲           ╱
   ╱          ╲        ╱
 ╱              ╲    ╱
```

**识别条件：** 一段急剧的旗杆行情后，出现平行四边形整理通道：
- **上升旗形**：急涨后小幅回调（向下倾斜通道）→ **看涨持续**
- **下降旗形**：急跌后小幅反弹（向上倾斜通道）→ **看跌持续**

**交易含义：** 趋势中继形态，突破通道延续原方向。

---

#### 17. 圆弧顶 / 圆弧底（Rounding Top/Bottom）

**示意图：**
```
圆弧顶（看跌）：           圆弧底（看涨）：
    ╱────╲                ╲────╱
   ╱      ╲               ╲    ╱
  ╱        ╲               ╲  ╱
 ╱          ╲               ╲╱
```

**识别条件：** 价格走圆弧轨迹，顶部/底部区域成交量先增后减。

**交易含义：** 缓慢的反转过程，可靠性较高但形成时间较长。

---

#### 18. V型反转 / W底 / M头（V-Reversal）

**示意图：**
```
V型反转：               W底（同双底）：    M头（同双顶）：
 ╲╱                    ┗┓    ┏┛          ┃    ┃
                        ┃    ┃           ┗┓    ┏┛
```

**识别条件：** 急剧的下跌后迅速反转上涨（或反之），形成V/W/M形状。

**交易含义：** V型反转表示市场情绪极端转变，W底和M头同双顶/双底形态。

## 注意事项

1. **置信度评分**：基于形态的完整程度、成交量配合、所处趋势位置等因素综合计算（0-100%）
2. **确认原则**：单根K线形态需后续K线确认，多根形态可靠性更高
3. **结合使用**：建议将形态识别结果与技术指标（均线、MACD等）和基本面分析结合使用
4. **风险提示**：本工具仅供技术分析参考，不构成投资建议
